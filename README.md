# 🌦️ Previsão do Tempo

Aplicação web simples que permite buscar o clima de qualquer cidade em tempo real utilizando a API do OpenWeather.

---

## 🚀 Funcionalidades

* 🔍 Busca de cidade em tempo real
* 🌡️ Exibição de temperatura atual
* 📈 Temperatura máxima e mínima
* 💧 Umidade do ar
* 💨 Velocidade do vento
* 🌥️ Ícone dinâmico do clima
* ⚠️ Tratamento de erros (cidade inválida)

---

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* API: OpenWeather

---

## 📸 Interface

Interface moderna com design clean, utilizando:

* Gradiente de fundo
* Cards informativos
* Ícones do Font Awesome
* Layout responsivo

---

## ⚙️ Como usar

1. Clone o repositório:

```bash
git clone https://github.com/seu-usuario/seu-repositorio.git
```

2. Abra o arquivo `script.js` e adicione sua chave da API:

```js
const apiKey = 'SUA_API_KEY_AQUI';
```

3. Abra o arquivo `index.html` no navegador

---

## 🔑 Como obter a API Key

1. Acesse: https://openweathermap.org/api
2. Crie uma conta
3. Gere sua API Key gratuita

---

## ⚠️ Observações

* A aplicação depende de conexão com internet
* A API gratuita pode ter limites de requisição
* Certifique-se de inserir corretamente sua API Key
